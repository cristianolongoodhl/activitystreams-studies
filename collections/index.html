Some Use Cases for Activity Streams Collections

In order to clarify the semantics of Activity Streams collections, this page reports some scenarios of Collection objects c, with the chief aim to distinguish setups that are compliant with the specifications (Activity Vocabulary and Activity Streams) from those that are not.

For the scenarions which are recognized as compliant, the expected members of the collection c are reported.

This page is still in progress, waiting for feedbacks.

UC1. A generic collection with unordered items. 
{
  "@context": "https://www.w3.org/ns/activitystreams",
  "id":"c",
  "type": "Collection",
  "items": [
    {
      "id":"o1",
      "type": "Object"
    },
    {
      "id":"o2",
      "type": "Link"
    }
  ]
}

Download uc1.jsonld.

 
@prefix as: <https://www.w3.org/ns/activitystreams#> .

<http://example.org/c>
  a as:Collection ;
  as:items <http://example.org/o1>, <http://example.org/o2> .

<http://example.org/o1> a as:Object .
<http://example.org/o2> a as:Link .
